# V9 深度指标分析报告
> 日期: 2025-06-12 | 三个实验: BOK run1 (60步), BOK restart (12步), DrGRPO baseline (72步)

## 1. 核心发现：PPO Clipping 从未激活

### 数据证据
| 实验 | 步数 | clipfrac_lower | clipfrac_higher |
|------|------|----------------|-----------------|
| BOK run1 | 60步全部 | **0.0000** | 0.0000-0.0001 |
| BOK restart | 12步全部 | **0.0000** | 0.0000-0.0001 |
| DrGRPO | 72步全部 | **0.0000** | 0.0000-0.0001 |

### 分析
- PPO clip bounds: [1-0.2, 1+0.28] = [0.8, 1.28]
- π_new(a|s)/π_old(a|s) **在所有实验的所有步骤中从未超出 [0.8, 1.28] 范围**
- 含义：lr=1e-6 下参数更新极其微小，策略几乎未发生变化
- **所有PPO保护机制（clip_ratio_low/high/dual）全部失效** — 策略移动太少，根本不需要限制

### 影响
```
有效 loss ≈ -mean(1.0 × advantage) ≈ -mean(advantage) ≈ 0
```
- ratio ≈ 1.0 → policy gradient 退化为 vanilla PG
- 信号极弱 → 表现为 reward/accuracy 的无趋势振荡

### 诊断标准
**健康训练应当看到 clipfrac > 0**，表明策略在"感受"到信赖域限制。
- clipfrac_higher > 0.05: 策略在正advantage方向移动足够远 → 正在学习
- clipfrac_lower > 0.02: 策略在负advantage方向移动 → 在"遗忘"坏行为

## 2. Actor指标趋势（BOK Run1, 60步）

### pg_loss
- 范围: [-0.033, +0.049]，正负各半
- **无上升/下降趋势** → 策略在随机漫步，未真正学习
- 对比 DrGRPO: pg_loss = [0.15, 0.40]（约 **20×** 更大，因无advantage clipping）

### entropy
- 范围: [0.491, 0.538]，极其稳定
- 后10步 (50-59) 轻微上升: 0.511→0.535
- 解读: 策略多样性没有明显下降，也没有因探索而显著增加

### kl_loss
- 趋势: 0.003→0.050（17×增长）
- 但 kl_coef × kl_loss = 0.03 × 0.050 = **0.0015**（vs pg_loss ~0.01）
- KL 惩罚仅占 total_loss 的 ~10% → 不是约束因素

### grad_norm
- 通常: 0.5-1.7，稳定
- 异常: Step 32 = **5.055** (唯一突刺)
- 对比 DrGRPO 崩溃前: grad_norm = 2.0-5.6，崩溃中 step 42 = **9.082**

### lr 调度
- Warmup: steps 0-8 从 0→1e-6（8步线性warmup）
- Steps 8-59: 恒定 lr=1e-6

## 5. BOK Restart vs Run1 对比

### 配置差异
| 参数 | Run1 | Restart |
|------|------|---------|
| BOK_CLIP | **3.0** | **4.0** |
| kl_coef | 0.03 | 0.01 |
| 起始检查点 | checkpoint-3537 | checkpoint-3537 (相同) |

### 指标对比（前12步）
| 指标 | Run1 | Restart | Δ |
|------|------|---------|---|
| pg_loss 范围 | [-0.016, +0.049] | [-0.011, **-0.051**] | restart全负 |
| pg_loss 均值 | +0.002 | **-0.028** | restart更"有效" |
| entropy | 0.492-0.519 | 0.492-0.519 | 相同 |
| kl_loss | 0.003-0.026 | 0.004-0.021 | 相当 |
| low_var(step1) | 80/1024 (7.8%) | **304/1024 (29.7%)** | restart **3.8×** |
| n_zero_std(step1) | 5/64 | **19/64** | restart **3.8×** |
| adv_mean | 0.002 | **0.031** | restart 16× |
| adv_std | 0.588 | **0.488** | restart 更窄 |
| WARNING次数 | **0** | **4** (每步都触发) |

### 解读
1. **restart pg_loss 全负** — BOK_CLIP=4.0 放大了正advantage的上界，梯度方向更一致
2. **但 low_var=29.7%** — 29.7%的样本处于低方差退化状态（group_std≈0），使用drgrpo fallback
3. **净效果 ≈ 1.0×** — 更强advantage (+33%) × 更少有效样本 (-24%) ≈ 相消
4. restart 持续触发 WARNING 是严重信号: "Consider: increase kl_coef, increase tau, disable DAPO filter"

> **结论**: BOK_CLIP=4.0 不推荐。保持 BOK_CLIP=3.0。

## 6. DrGRPO 崩溃完整时间线

### 阶段划分

**Phase 1 — 正常 (Steps 1-36)**
- pg_loss: 0.24-0.40 (20× BOK)
- entropy: 0.49→0.73 (缓慢上升)
- kl_loss: 0.005→0.181 (60× 增长!)
- format_fail: 0.003-0.035 (正常)

**Phase 2 — 临界 (Steps 37-39)**
- entropy: 0.78→0.92 (急升)
- format: 0.95→0.59
- format_fail: 0.05→**0.41**

**Phase 3 — 雪崩 (Steps 40-44)**
- format_fail: 0.79→**0.97**
- overall: 0.19→0.03
- entropy: 0.89→**1.14**
- grad_norm step 42: **9.082** (峰值)

**Phase 4 — 死亡 (Steps 65-71)**
- format_fail: **1.000** (100% 格式失败)
- overall: **0.000**
- entropy: **1.51-1.68** (3× 正常值)
- kl_loss: **0.73-1.33** (100× 初始值)
- pg_loss: 降至 0.02 (与 BOK 相当，因为 format_rejection 将所有 reward 置零 → 全组相同 → advantage≈0)

### 根因链
```
DrGRPO无advantage clipping
→ 大负advantage推动策略远离当前策略
→ entropy上升(策略变散)
→ 格式遵循能力下降
→ format_rejection将format_fail样本的overall置零
→ 更多全零组 → 更大负advantage
→ 正反馈死亡螺旋
```

### 关键证据: answer/point 在崩溃中不降
| 阶段 | overall | answer | point | format_fail |
|------|---------|--------|-------|-------------|
| 正常(1-36) | 0.79-0.87 | 0.76-0.85 | 0.80-0.92 | 0.003-0.035 |
| 崩溃(40-63) | 0.02-0.18 | **0.70-0.87** | **0.76-0.92** | 0.79-0.98 |
| 死亡(65-71) | 0.00 | **0.71-0.78** | **0.76-0.84** | 1.000 |

→ 模型的推理能力并未丧失，纯粹是**格式遵循崩溃**

## 7. 综合诊断与 V10 建议

### 核心瓶颈排序
| # | 瓶颈 | 严重度 | 可控性 |
|---|------|--------|--------|
| 1 | **lr=1e-6 太小 → PPO不起作用** | 致命 | 简单调参 |
| 2 | answer振荡0.80无趋势 | 关键 | 需lr/CLIP优化 |
| 3 | consistency_violation ~7.3% | 中等 | 需reward设计 |
| 4 | low_var ~11% (run1) | 轻微 | 现有fallback处理 |

### V10 推荐配置
```bash
# 核心变更
lr=3e-6              # 3× 当前 (最重要的变更!)
kl_coef=0.05         # 提高约束强度，防止高lr导致发散
BOK_CLIP=3.0         # 维持不变，避免low_var爆炸
warmup_steps=8       # 缩短warmup (8步 vs 当前8步，已OK)

# 监控关键指标
# ✅ clipfrac_higher > 0.01 → 策略在移动
# ✅ answer_score 连续上升
# ⚠️ entropy > 0.8 → 警告，可能需要增大kl
# ❌ format_fail > 0.1 → 立即停止
```

### 预期效果
- lr=3e-6 相比 1e-6: 参数更新 **3×** → ratio会偏离1.0 → clipfrac应出现正值
- kl_coef=0.05 安全网: 即使ratio增大，KL惩罚能有效约束策略偏移
- BOK_CLIP=3.0: 验证有效(run1无WARNING)，保守稳定

### 备选激进方案
```bash
lr=5e-6, kl_coef=0.08  # 如果3e-6的clipfrac仍然很低，可进一步提升
```
