### 5.2 V24: lr=1.5e-6 的影响

- V24 answer_max=0.843 是 V21-V24 中最高的
- 但 best val=0.7713 反而比 V22/V23 低

**结论**: 更高lr提升了训练reward但降低了泛化能力 (train-val gap增大)。

### 5.3 为什么 V21-V24 都打不过 V12?

| 差异 | V12 | V21-V24 |
|------|-----|---------|
| 数据 | easy only (11,455) | easy+hard (13,647) |
| hard样本 | 0% | 13.3% (1,808+384) |
| answer start | 0.849 | 0.71-0.74 |
| grad | 0.552 | 1.0-2.5 |
| max_grad_norm | 0.5 | 1.0 |

1. **数据毒性**: easy+hard混合数据中hard样本（低answer正确率）拉低了average reward baseline，reduce了对easy样本的有效学习信号
2. **梯度噪声放大**: V12的max_grad_norm=0.5 vs V21+的1.0，V12有更强的梯度裁剪
3. **warm-start vs SFT-start**: V22-V24从V21-step60 warm-start，继承了V21的策略偏差
4. **关键**: V12的val score只有0.775 (pixmo-test内部评估)，但**独立评测是81.47%**，说明pixmo-test的val score和实际评测有~4pp差距

- 起始answer=0.392 (V23-step213基座对hard数据的表现)
- 最高answer=0.495 → 短期提升但幅度有限
- grad_max=12.360 → 极端梯度波动

## 6. 综合建议

1. **回归V12策略**: max_grad_norm=0.5 被验证更好，建议后续版本统一使用
2. **数据分离训练**: 先在easy上训练到收敛(如V12策略)，再用低lr微调hard
3. **hard样本课程学习**: 不要一次性混合，而是渐进增加hard比例
4. **ppo_epochs=1**: 已验证等效于ppo=2但更稳定
5. **lr=1e-6**: 1.5e-6导致泛化下降，维持1e-6

## 8. 结论：V12优势的根本原因

### 8.1 核心差异排序（影响程度从大到小）

1. **max_grad_norm=0.5 vs 1.0** (最大影响)
   - V12 grad_mean=0.55 → 有效截断大梯度，保证平稳学习
   - V21-V24 grad_mean=1.0-2.5 → loss landscape 探索更喘急
   - V12 0 spikes vs V21-V24 270-480 spikes
   
2. **纯 easy 数据 vs easy+hard 混合** (第二大影响)
   - V12 answer start=0.849 → 基座已经很好，RL 只需微调
   - V21-V24 answer start=0.71-0.74 → hard 样本拉低 baseline
   - Hard 样本梯度方差大，降低所有样本的有效学习信号

3. **ppo_epochs=2 在低 grad_norm 下的独特优势**
   - V12 (ppo=2, grad_norm=0.5): 梯度被截断，ppo=2 在截断范围内多次更新 → 精细微调
   - V22 (ppo=2, grad_norm=1.0): 梯度未被充分截断，ppo=2 放大了波动 → 有害

4. **SFT fresh start vs warm-start**
   - V12 从 SFT 开始的策略参考模型和初始策略完全一致 → KL 从 0 开始
   - V22-V24 从 V21-step60 warm-start → 起始就有策略偏差

## 9. 深度追加分析 (根据讨论反馈)

### 9.1 grad_norm=0.5 vs 1.0: 第一性原理修正

**之前的错误**: 我之前说"clip=0.5会忽略hard样本"是错的。

**精确机制**:
`clip_grad_norm_` 对**聚合后的整个batch梯度**做裁剪，不区分easy/hard样本的贡献。
裁剪只限制总更新**幅度**，梯度**方向**(包含easy和hard的混合信号)不变。

**实测数据**:

| 实验 | clip值 | 原始grad median | 被裁剪比例 | 裁剪后grad方差 |
|------|:-:|:-:|:-:|:-:|
| V12 (easy, clip=0.5) | 0.5 | 0.845 | **100%** | **0** |
| V21 (easy+hard, clip=1.0) | 1.0 | 1.117 | 63% | 0.161 |
| V23 (easy+hard, clip=1.0) | 1.0 | 0.901 | 38% | 0.168 |
| 假设: V23数据+clip=0.5 | 0.5 | 0.901 | **100%** | **0** |
| 假设: V23数据+clip=0.7 | 0.7 | 0.901 | 82% | 0.046 |

**V12的真正优势不是clip=0.5本身, 而是 clip=0.5 × ppo=2 的组合效应:**

1. clip=0.5 × ppo=2 → 每batch最大总更新=1.0 (两次×0.5)
2. 但分两步: 第一步更新后, 在新参数上重新计算梯度再做第二步
   → 等效于"smaller lr + second-order correction"
3. V22 (clip=1.0 × ppo=2) → 每batch最大总更新=2.0 → 步长太大 → 震荡

**推荐V25的grad_norm设置:**

| 方案 | ppo | clip | 总更新上限 | 说明 |
|------|:-:|:-:|:-:|------|
| A (复现V12) | 2 | 0.5 | 1.0 | 最安全, 验证over |
| B (折中) | 1 | 0.7 | 0.7 | 保留更多梯度信息 |
| C (等效降lr) | 1 | 1.0 | 1.0 | lr=7e-7代替clip |

### 9.2 189 no-mask 样本过采样 ×2 评估

**精确定位**: 189个样本全部在hard_only数据集中, V12 easy数据**0个no-mask** (100%匹配)

**过采样效果的量化推导**:

```
过采样前: 189/13647 = 1.38%, 每batch(1024)期望14个
过采样后: 378/13836 = 2.73%, 每batch期望28个, 增量14

这14个额外样本的reward信号:
  answer (60%权重): 完全准确
  format (10%权重): 完全准确
  point  (30%权重): stat_mask_sim fallback, 误差<0.005

对整体信号的影响: 2.7% × 0.005 × 30% = 0.00004 ≈ 可忽略
```

**过采样的有效前提条件**:
- 这189个样本必须在pass@16中有正确trajectory → 否则过采样无用
- 如果pass@16有正确trajectory, 标准BoK-GRPO已经会学 → 过采样只是微增频率

**结论**: 过采样有**微弱正效果**(更多学习机会), 但不是突破口。如果要提升这189样本:
1. 最有效: 为它们生成SAM mask → 完整的dense point reward
2. 次之: 过采样×2 + 部署stat_mask_sim → 低成本微改善

### 9.3 BoK-GRPO 优化空间分析

当前实现核心路径: `verl/trainer/core_algos.py` L424-L813

**当前算法流程** (K=16 trajectories per prompt):
1. 计算每条trajectory总分 s_i = Σ_t r_{i,t}
2. 判断easy/hard: pass_rate = (s_i > θ_score的比例) > θ_easy(0.50)?
3. Easy组: A_i = clip((s_i - μ)/σ, ±2.5) × easy_scale
4. Hard组: z_i = (s_i-μ)/(σ+ε) → softmax(z/τ) → A_i = (w_i - 1/K)×K
5. 最终clip: A_i ∈ [-BOK_CLIP, BOK_CLIP] (V23实际=4.0, 不是12.0)
6. token级广播: A_{i,t} = A_i × mask_{i,t}

**已识别的6个优化点** (按影响排序):

**[高] 1. Easy/Hard路由判据与目标不一致**
- 现状: 用综合分 s_i > θ_score 判定easy/hard
- 问题: 混合了point+format分, "答案错但点位高"的可能被判为easy
- 修复: 改为answer-only pass_rate门控
- 预期: 更精准的hard组识别 → BoK winner更有效

**[高] 2. 全错组仍给"最不差的错解"正advantage**
- 现状: 全错组只做cap, 最好的错解仍获正advantage
- 问题: 推高错误轨迹概率, 与pass@1目标冲突
- 修复: 全错组强制A_i ≤ 0, 或只学过程质量(point)
- 预期: 避免"鼓励错误答案"的反效果

**[中高] 3. winner_boost/quality_bonus 全都关闭**
- 现状: winner_boost=0, quality_bonus=0
- 问题: 对稀有正确trajectory没有额外放大
- 修复: 适度开启winner_boost=1.5~2.0
- 预期: 稀缺正例获得更大优势 → 直接推动pass@1

**[中] 4. token级masked_mean偏向长trajectory**
- 现状: 长trajectory产生更多token → 在loss中权重更大
- 修复: trajectory级聚合后再batch平均
- 预期: 减少长度偏置

**[中] 5. Easy分支±2.5固定clip vs Hard分支可更大**
- 现状: easy组advantage上限2.5, hard组可到BOK_CLIP=4.0
- 修复: easy_scale随训练衰减, 梯度预算转向hard
- 预期: 渐进式课程学习效果

**[中] 6. BOK_CLIP=4.0可能过保守**
- 现状: 固定clip=4.0, K=16时理论最大优势≈15
- 修复: 自适应clip (如跟踪|A|的P95)
- 预期: 更好的exploration-exploitation平衡
