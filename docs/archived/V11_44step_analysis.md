## 诊断结论

### 积极面
1. **V-shape恢复有效**: 模型从Q3低谷成功反弹
2. **S31达到am=0.8811**: 最佳单步answer_mean
3. **pm持续提升**: Q5 pm=0.8788为最高区间
4. **format几乎无错**: format_fail avg~0.015

### 风险面
1. **grad_norm后期不稳定**: S38-S41密集spike(4.8,2.1,4.85)，训练稳定性恶化
2. **KL divergence加速**: S31后kl倍增，S33 kl=0.038最高
3. **am振荡增大**: S31(0.881)→S33(0.765)→S40(0.862)→S41(0.803)，幅度>10pp
4. **BoK路由退化**: S41 ac%降至28.1%，easy%回升至34.4%

### 建议下一步
1. **保存S31 checkpoint**: 这是最佳checkpoint，am=0.8811, pm=0.8957
2. **评估S31 vs S40**: 两者都是高分步骤，benchmark对比
3. **考虑提前停止**: 后续train可能更多spike风险
4. **V12改进方向**:
   - 增大kl_coef: 0.02→0.03-0.05，抑制KL发散
   - 增大ppo_epochs: 2→3-4，激活clipfrac
   - adaptive grad_norm: 当连续spike时降低lr
   - 或切换到Dr.GRPO/标准GRPO作为baseline对比
